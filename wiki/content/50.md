# VFX

The VFX Editor builds particle effects — fire, smoke, sparks, magic, weather, impacts — and exports them to Unity and Unreal.

Open it from the **VFX** tab in the header. Effects are saved to your asset library like any other asset, and can be opened again from the Assets page.

## The screen

| Area | What it is |
|---|---|
| **Board** (middle) | The nodes that make up the selected system. See [Nodes](/wiki/55). |
| **Preview** (right) | The effect running, live. Everything you change is applied immediately. |
| **Timeline** (bottom) | One track per system, and the transport. See [Timeline](/wiki/54). |
| **Parameters** (left) | Appears when you select a block or a node. |

## Start from a preset, not an empty board

Nobody learns a particle system from a blank page. Click **VFX Presets…** in the toolbar and pick something close to what you want — there are 54 effects across 11 categories — then change one number at a time until you understand what each one does.

See [Presets](/wiki/51).

## An effect is made of systems

One effect can contain several **systems**, and each system is an independent cloud of particles with its own capacity, its own look and its own timing.

An explosion is usually three or four systems: a fireball, some debris, a smoke column, maybe a shockwave ring. They are separate because they need different lifetimes, different blending and different start times — and the [Timeline](/wiki/54) is where you decide when each of them fires.

The board shows **one system at a time**. Pick which one with the track list on the left of the timeline.

## The toolbar

| Control | What it does |
|---|---|
| **VFX Presets…** | The starter library. |
| **Sprite…** | Generate a particle texture with ComfyUI. See [Sprite Generation](/wiki/52). |
| Keyboard icon | The shortcut sheet. Also opens with `?`. |
| Camera icon | Save the current frame as a PNG. |
| Grid icon | Bake the effect into a flipbook. See [Sprite Sheet](/wiki/53). |
| **Grid / Scale / Emitters / Stats / Ortho / Profile** | Viewport overlays. **Emitters** draws a wireframe of every emitter shape, which is the fastest way to understand where particles are coming from. |
| **Detail** | How much of the interface is shown: `guided` hides advanced properties, `full` adds a raw JSON view on the selected node. |
| **Target** | Unity, Unreal or both. Setting one raises a warning on any block that engine cannot reproduce exactly. |

## The diagnostics strip

Under the board. With no problems it reads something like:

```
✓ No problems · ~1,400 particles · 1 draw call · Unity + Unreal ready
```

Those numbers are worth watching. **Dropped** particles in the stats window mean the effect asked for more than its capacity allows, and the excess was simply not created.

Most warnings come with a **fix button** that applies the change for you. It counts as one undo step.

## Exporting

**Export…** writes a bundle folder containing `manifest.json` (the graph, the compiled effect and the engine compatibility table) plus every texture and mesh the effect uses.

Tick **Include the Unity importer** and the folder also gets a `UnityImporter/` with the plugin and a note on how to install it — so the exported folder is everything the person opening it needs.

## Saving

**Save** writes the effect to your library and renders a card thumbnail from the frame you are looking at. Pause the timeline on the moment that looks best before saving.

There is no autosave to the server, but unsaved work is kept in your browser and offered back if you reload by accident.
