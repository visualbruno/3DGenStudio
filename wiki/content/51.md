# Presets

Ready-made effects to open and change. **This is the way to start** — nobody learns a particle system from an empty board.

Click **VFX Presets…** in the toolbar.

## Finding one

- **Search** matches names, descriptions, categories and tags — so "vortex" finds the effects that use one, not just the ones called that.
- The **category rail** on the left filters, with live counts.
- **Filter chips** narrow by behaviour (*Loops*, *Plays once*, *Staged timing*), by level (*Beginner*, *Intermediate*, *Advanced*) and by technique (*Additive*, *Collision*, *Turbulence*, *Vortex*, *Attractor*, *Mesh particles*, *Sub-emitters*…). Picking several requires all of them.

Every card carries a description and, on hover, a **"teaches"** list naming the techniques it demonstrates. That is the point of the library: not "here is a nice explosion" but "here is how staged timing works".

## Opening one

Click a card. It replaces the effect you have open — if that has unsaved changes you are asked first.

A preset is a **starting point, not a link**. Once opened it is an ordinary effect: change anything, and **Save** writes a new asset. The preset itself is untouched.

## Sprites and meshes

Presets draw with real textures and chips — a flame wisp, a smoke puff, spark streaks, rock debris — not plain blobs.

Those files ship with the app. The first time you open a preset that needs one, it is **added to your image or mesh library** under a `VFX ` name, and you are told how many were added. Every open after that reuses the copy already there, so nothing accumulates.

They are ordinary library assets: you can open, edit or replace them like any other.

*(Why it works this way: a preset cannot store an asset id, because ids are specific to one installation and would point at nothing — or at someone else's image — on another. It names a file instead, and the file is installed when the preset is opened.)*

## Editing presets

Only on an installation set up for authoring. Everyone else sees a **Read-only** badge, and the library is fixed.

With authoring enabled, each card gets three actions on hover:

| Action | What it does |
|---|---|
| **Edit** | Change the name, category, description, tags and "teaches" list. |
| **Camera** | Render a card thumbnail from the preset itself. |
| **Delete** | Remove it. |

Plus two buttons in the header: **Thumbnails**, which fills in every missing card image in one pass, and **Save current as preset**, which turns the effect you have open into a new library entry.

Presets are files on disk, so adding one is dropping a file rather than a code change.
