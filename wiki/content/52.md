# Sprite

A particle's texture. This page covers generating one with ComfyUI; assigning one is the **Sprite Texture** block described in [Output](/wiki/59).

Click **Sprite…** in the toolbar. It needs a system selected — the board already tracks which one you are editing, so it gives the sprite to that one.

## Why generated sprites work at all

ComfyUI produces no transparency, which sounds fatal for a particle texture. It is not, because of how additive blending works.

**With additive blending, black is already invisible.** The shader adds the texture as light, so a black background contributes nothing and *is* the transparency. That is why every prompt here is steered onto a pure black background, and why fire, sparks, magic, glows and explosions — most of what a particle sprite ever is — need no alpha channel at all.

Alpha only matters for **alpha-blended** sprites: smoke, dust, debris, decals, where black renders as a black blob. For those, generate the image, then run one of the **Remove Background** workflows on it in the Image Editor and pick the resulting edit as your sprite instead.

## Generating one

1. **Pick a workflow.** The list is sorted by name and shows only workflows that take a text prompt and return an image with no image of their own — the "Gen Image with …" ones. Inpainting and projection workflows need an input image, so they cannot be driven from a prompt alone here.
2. **Describe it**, or click a preset: *Soft glow*, *Flame wisp*, *Spark streak*, *Smoke puff*, *Magic rune*, *Debris chip*. The black-background instruction is appended for you.
3. **Adjust anything else.** The whole parameter list is shown — seed, steps, sampler, resolution — so you are not stuck with one dice roll. Untouched fields use the workflow's own saved defaults.
4. **Generate.** The result is assigned to the selected system's Output *and* saved to your image library, so other effects can use it.

## Making a generated sprite look right

**Set the blend mode to additive** on the Output node. That is the mode these sprites are made for.

If the effect shows a faint grey **haze** around each particle, raise **Black point** on the Sprite Texture block. A generated background is often nearly-but-not-quite black, and additive blending adds that remainder once per overlapping particle. Raise it until the haze clears; too far and the sprite loses its dimmest edges.

Good prompts for particle sprites are simpler than you would expect. One clear shape on black, centred, no border, no text. Detail that reads beautifully at full size disappears at 32 pixels across, which is the size a particle usually is.

## Sprite sheets

To generate an animated flipbook rather than a single image, bake one from an effect you already have — see [Sprite Sheet](/wiki/53). That gives you a sheet whose frames are guaranteed to be consistent, which a text-to-image model cannot do.
